# Multi-LLM Debate: Heterogeneous Model Collaboration for Improved Reasoning

// Authors: David I.K. (DSIndieAI)

ABSTRACT: We present Multi-LLM Debate, orchestrating solver, critic, verifier, and synthesizer agents to boost GSM8K math accuracy to 80% (+26.7% overall).

 

Key Benchmarks:

• Single Model: 0% - 20% Accuracy

• 3-Model Debate: 26.7% - 80.0% Accuracy

• Cost: $0 (Free-tier Groq/Gemini API mesh)
